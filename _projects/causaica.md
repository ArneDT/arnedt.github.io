**Causal Actionable Understanding via a diagnostic Assistant for Interactive Root Cause Analysis**

Machine failures cause large financial losses through downtime, service interventions and warranty claims. Anomaly detection has improved a lot, but finding the actual root cause of a failure in complex machinery is still a slow, manual process that relies heavily on human intuition. Classic methods such as the Five Whys, fishbone diagrams and fault tree analysis are either too subjective or too resource-intensive, and they often miss novel failure patterns.

CausAICA develops a root cause analysis framework with an interactive diagnostic assistant. It uses causal AI, multimodal data and engineering models to uncover _why_ failures occur, linking sensor data, maintenance logs and expert insight. The framework aims to make failure investigations more efficient, give explainable insights for corrective actions, and highlight blind spots where critical data is missing so monitoring can be improved.
