ManGO is the KU Leuven research data management platform built on [iRODS](https://irods.org/).
**ManGO-fsspec** is a [filesystem-spec](https://filesystem-spec.readthedocs.io/) backend implementation for iRODS, so data stored in ManGO can be accessed through the same file-like interface that Python tools such as pandas, xarray and Dask already use for local disks and cloud storage.
